[Pasted tips]
Tips, edge cases and FAQs
Free hosting wakes slowly. The API runs on Render, so the first call after idle time can
take up to a minute. Call GET /health first and use a generous timeout and retries.
Keep secrets out of code. Store any x-api-key value or Google credentials in
environment variables or a local secrets file that is not shared.
Same name every time. Use the same sender value on every push, so the dashboard
groups your entries under one learner (check GET /api/learners ).
Ask Claude for JSON. A strict output format (fields and allowed values) makes the
API step far more reliable than free text.
Test with edge cases. Try an email for another participant, an empty file, a duplicate
file and an email with the assignment details missing.
Clean up test data. Test entries can be removed with DELETE
/api/entries/{entry_id} ; delete only your own.
Do not process the same file twice. Record a file's name or ID after pushing it.
